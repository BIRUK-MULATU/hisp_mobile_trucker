How Passwords Are Protected

The device never stores a recoverable password — online or offline.

Online Login Server reachable

  • 1 Username + password entered on device
  • 2 Sent as HTTPS Basic Auth to the DHIS2 server (TLS-encrypted in transit)
  • 3 Server validates credentials — password never touches local storage

Offline Login No network

  • 1 On successful online login, a one-way verifier is generated
  • 2 Verifier + random salt saved in Android Keystore / iOS Keychain
  • 3 Later offline attempts recompute & compare — password itself is never stored
verifier = SHA256( salt : serverUrl : username : password )
Never recoverable +

The verifier is one-way. There is no operation that turns it back into the password — by design, not by policy.

Random per-user salt +

Generated with a cryptographically secure RNG for every user, preventing precomputed lookup-table attacks.

Bound to the server URL +

A verifier created for one DHIS2 instance can't be replayed to validate a login against a different server.

Hardware-encrypted at rest +

Stored via Android Keystore / iOS Keychain (encrypted shared preferences) — not a plain file on disk.
